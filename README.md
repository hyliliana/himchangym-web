# 힘찬짐 회원용 웹

회원이 자기 이용권·예약·PT 피드백를 확인하는 Next.js 앱입니다. 이용권 구매 기록은 데스크가 등록하며 실제 결제 기능은 없습니다.

## 실행

Node.js 20.9 이상이 필요합니다.

```sh
pnpm install --frozen-lockfile
cp .env.example .env.local
# BACKEND_URL을 NestJS 서버 주소로 지정
pnpm dev
```

개발 주소: http://localhost:3100. `pnpm build`, `pnpm start`로 프로덕션 실행합니다. Vercel에는 `BACKEND_URL` 환경 변수만 서버 전용으로 설정합니다. 주소에 `/api` 접두사를 붙이지 않습니다.

## 동작

- 이메일 회원가입·회원 로그인·로그아웃
- 현재/지난 이용권, 전체·사용·남은·예약 확보·새 예약 가능 횟수
- 현재·지난 이용권 구매 내역의 직원 등록 영수증 열람, 확대·화면 맞춤·등록 전 빈 상태
- 이용권·트레이너·날짜·정시 선택 예약, 취소 확인, 예약 상태별 내역
- 트레이너의 PT 피드백 읽기, 이름·연락처 저장/수정, 비밀번호 변경
- 직원이 발급한 임시 비밀번호로 첫 로그인하면 비밀번호 설정 후 앱 이용
- 예약된 수업의 날짜·시간 변경: 기존 이용권과 트레이너 유지, 충돌 시 기존 예약 보존
- 카카오톡·문자 수신 선택 저장/철회 및 마지막 변경 시각 확인 (실제 발송 미연동)
- 신규 회원은 이용권 등록을 데스크에 문의하도록 안내
- loading/empty/error 안내와 좁은 화면 대응

## 인증과 범위

브라우저는 같은 출처의 `/api/[...path]`만 호출합니다. Next.js 서버가 `gym_session` HttpOnly / SameSite=Lax 쿠키를 읽어 백엔드 Bearer 토큰으로 전달합니다. 프로덕션 쿠키에는 Secure를 적용합니다. 로그인 요청은 회원 역할로 고정하고 회원 이외의 로그인 응답은 거절합니다. 직원 경로는 프록시 허용 목록에 없습니다. 수정 요청의 Origin host와 요청 Host를 비교해 다른 출처 요청을 거절합니다. 회원의 영수증 경로는 GET만 허용하며 업로드 기능은 직원 앱에만 있습니다.

영수증은 `GET /member/passes/:id/receipts`로 조회합니다. 백엔드가 이용권 소유권을 검사하며, 회원 화면은 JPEG·PNG·WebP 데이터 이미지만 표시합니다. 영수증은 버튼을 눌렀을 때만 불러오며, 창은 키보드 초점 이동·Escape 닫기·닫기 버튼을 지원합니다. 확대 이미지 영역은 키보드로 스크롤할 수 있습니다.

백엔드가 회원 소유권·횟수·중복·근무일·만료일·상태 전이의 최종 검증을 담당합니다. 브라우저에는 토큰이나 DB 접속 정보를 전달하지 않습니다. 에러는 사용자 메시지만 전달합니다.

## 디자인

사용자가 승인한 최종 디자인은 [getdesign.kr 직방 카탈로그](https://getdesign.kr/services/zigbang)의 시각 언어입니다. `DESIGN.md`는 승인 작업본에 포함된 원문 685줄을 수정 없이 보존했습니다. 작성자 [ChangSik Yoon (CaesiumY)](https://github.com/CaesiumY/ko-design-md)의 카탈로그 서술·정규화 토큰은 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)을 따르며, 전문과 적용 범위는 `LICENSE-DESIGN-CONTENT`에 있습니다. 원자료의 상표·폰트·사진 등 권리는 별도입니다.

직방의 발행 오렌지 `#FF6905`와 회색 팔레트, Pretendard, 4px 컨트롤 모서리, 12px 카드 모서리, 48px 기본 버튼과 52px 입력을 사용합니다. 주황색을 어둡게 바꾸지 않고 버튼 글자에 gray10 잉크를 써서 대비를 확보했습니다. 이 의미별 토큰 이름·모바일 분기·회원 업무 레이아웃은 힘찬짐의 적용 판단이며 직방이 발행한 역할·반응형 토큰이라고 주장하지 않습니다. `DESIGN-APPLICATION.md`에서 출처와 적용 판단을 확인할 수 있습니다.

`public/brand/himchangym-symbol.svg`는 승인된 힘찬짐 H 덤벨 심볼입니다. 직방 로고·워드마크·부동산 카피는 사용하지 않았습니다. 메뉴·이용권·예약·기록·회원·영수증에는 텍스트와 함께 SVG 아이콘을 표시합니다. Pretendard는 SIL OFL 1.1 서체이며 기존 jsDelivr CSS로 불러옵니다. 외부 폰트에 연결할 수 없으면 운영체제 한글 글꼴로 표시됩니다.

통합은 제출본 `b2681aae0a2e6ba9cebfe3d4f03a7e8cb5618b59`에서 `chief/himchangym-design-update` 브랜치로 분리했습니다. 승인 작업본과 현재 소스를 비교한 표현 패치만 적용했고 기존 영수증·인증·예약·프로필 API 코드는 보존했습니다. 제출본 브랜치 `chief/himchangym-web`은 그대로 유지합니다. 이 변경은 과제 재제출을 실행하지 않습니다.

## 확인

```sh
pnpm typecheck
pnpm build
```

기능 실검증은 백엔드를 연결한 뒤 회원가입 → 빈 이용권 안내 → 데스크 등록 후 이용권 → 예약 → 취소 → 완료·노쇼·메모 조회 → 프로필 수정 순서로 진행합니다. 기존 실사용자 개인정보 대신 가상 데이터만 사용합니다.

2026-11-05 로컬 NestJS·PostgreSQL 연동 API 검사에서 회원가입, 신규회원 빈 이용권, 데스크 이용권 등록 후 회원 조회, 예약 시 확보 1·가능횟수 1 감소, 취소 시 차감 없이 복구, 프로필 수정, 잘못된 현재 비밀번호 입력 시 기존 세션 유지, 비밀번호 변경, 로그아웃 후 401을 확인했습니다. 회원 BFF의 관리자 경로 404, 다른 Origin 수정 요청 403, 응답 토큰 제거, HttpOnly 쿠키도 확인했습니다. 전체 브라우저 동작과 배포 환경 검수는 별도로 진행합니다.

두 프런트 앱의 쿠키명은 계약상 `gym_session`입니다. 로컬에서는 같은 hostname의 다른 포트끼리도 쿠키가 공유되므로 회원 `127.0.0.1` / 직원 `localhost`로 구분하거나 브라우저 세션을 나누세요. 배포 시에는 각 앱의 별도 도메인에 쿠키가 저장됩니다.

## 2026-11-06 기능 보완

`chief/entity-lifecycle`은 디자인 개편본에서 분리한 기능 보완입니다. 예약 변경은 `POST /member/reservations/:id/reschedule`로 처리하며, 서버가 다른 회원의 예약·시작된 수업·만료/휴무/중복 시각을 거절합니다. 예약을 취소 후 새로 만들지 않아 실패 시 기존 예약이 유지되고, 예약 확보로 새 예약 가능 횟수가 0인 마지막 1회도 변경할 수 있습니다.

알림 수신 설정은 `GET/PATCH /member/notification-preferences`로 저장합니다. 기본은 두 채널 모두 선택하지 않은 상태이며 광고 수신 동의가 아닙니다. 화면은 발송 미연동 상태를 명시합니다. 직원이 회원을 삭제하면 새 로그인과 기존 세션이 차단되며, 복원 후에는 다시 로그인해야 합니다. 구매·영수증·지난 수업 기록은 보존됩니다.
